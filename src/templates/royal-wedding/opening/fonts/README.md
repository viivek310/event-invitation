# Noto Serif Gujarati

Variable font bundled locally from the official Google Fonts repository:

- Source: https://github.com/google/fonts/tree/main/ofl/notoserifgujarati
- File: `NotoSerifGujarati[wght].ttf`, stored here as `NotoSerifGujarati.ttf`
- License: SIL Open Font License 1.1; see the unmodified `OFL.txt` alongside it.

The local Next.js font loader supplies the font and preload. The opening waits for Gujarati font preparation before enabling its main animation. No Google Fonts request is made by the browser or build.
